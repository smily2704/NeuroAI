# Frontend — Neonatal EEG Analysis Platform

A full-stack starter project based on the supplied project specification.

## Stack
- Frontend: React + Vite
- Backend: FastAPI + SQLAlchemy
- Development database: SQLite by default; PostgreSQL can be configured with `DATABASE_URL`
- Authentication: JWT + password hashing
- EEG processing: CSV validation, real uploaded-signal preview, basic signal-quality checks, STFT spectrogram and band-power analysis
- PDF reports: ReportLab

## Important scientific boundary
The Nathan + Sumit seizure model/checkpoints were not included with the specification. Therefore, this project does **not** fabricate seizure predictions, confidence, localization, sensitivity, specificity, or clinical diagnoses. The ML adapter explicitly reports that the model is not configured until the actual model code and checkpoint are integrated. EEG statistics and signal-quality checks are descriptive, not a seizure diagnosis.

Do not use real patient data until the application has been reviewed, secured, and validated for the intended environment. This starter is not a certified medical device.

## Run the backend
Python 3.10+ recommended.

```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload
```

API docs: http://127.0.0.1:8000/docs

The development database is created automatically. A demo doctor account is created only when `SEED_DEMO_USER=true`:
- Email: `doctor@example.com`
- Password: `ChangeMe123!`

Change these credentials immediately; do not expose demo credentials in a deployed environment.

## Run the frontend
Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Vite prints the local URL, normally http://localhost:5173.

Optional frontend API setting: create `frontend/.env` and set:
`VITE_API_URL=http://127.0.0.1:8000`

## Current included functionality
- Login UI and JWT-backed login
- Doctor and patient role-aware app shell
- Dashboard overview and patient directory
- Patient creation and patient details/history endpoints
- CSV EEG upload and validation
- Signal metadata and real uploaded CSV waveform preview
- Basic per-channel descriptive statistics and signal-quality flags
- STFT spectrogram and frequency-band power endpoint
- Analysis endpoint that clearly reports model-not-configured rather than fake seizure events
- Doctor notes with internal/patient-visible visibility
- Clinician-authored prescriptions (never generated by ML)
- PDF report generation endpoint with disclaimer
- Report history/download endpoints
- Export current analysis metadata as JSON/CSV from API
- Dark/light theme toggle and responsive layout

## Not yet production-ready
The provided Nathan + Sumit model, checkpoint, scientific preprocessing code, dataset-specific channel mappings, clinical validation, production migrations, refresh-token rotation, audit logging, deployment secrets, cloud object storage, and full authorization/security review must be added before production use. EDF is not enabled in this starter; CSV is supported. The UI marks unavailable features rather than inventing outputs.

## PostgreSQL
Set `DATABASE_URL` in `backend/.env`, for example:
`DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/neonatal_eeg`
Install `psycopg[binary]` (included in requirements). For production, use Alembic migrations rather than relying on automatic table creation.
